## Как сравниваются модели

- Для каждой задачи один раз выделяем 20% строк на тест, затем используем это разбиение во всех работах. Для Sonar разбиение стратифицировано.
- Выбираем параметры по пяти фолдам на обучающей выборке. Масштабирование подгоняем внутри каждого фолда. В классификации максимизируем F1-macro, в регрессии минимизируем MAE.
- Оцениваем на тесте исходную и подобранную версии sklearn, собственную реализацию и собственную реализацию с теми же подобранными преобразованиями и параметрами. Настройки собственной модели отдельно по тесту не подбираем.
- Итоговые таблицы включают Accuracy для классификации, RMSE и R² для регрессии. В выводах отдельно отмечены модель, выбранная по CV, и лучший результат, наблюдавшийся на тесте.

## Результаты

| Задача | Модель sklearn по кросс-валидации | Качество на тесте |
| --- | --- | --- |
| Классификация | KNN с подбором | F1-macro 0,8803, Accuracy 0,8810 |
| Регрессия | Градиентный бустинг с подбором | MAE 1,6226 МПа, RMSE 1,9871 МПа, R² 0,9220 |

Своя реализация KNN получила такой же F1-macro. Собственный настроенный бустинг дал MAE 1,6349 МПа. Подбор помог не в каждом случае. У классификационного дерева sklearn F1-macro на тесте снизился с 0,8286 до 0,7379.
